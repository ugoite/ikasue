ikasue is a framework-neutral component system for information-dense workspaces. Every region is treated as ordered space on one shared plane: new information enters from the edge where it belongs and gives existing information room.

## Where to start

- Read the [overview](overview/) for the package, component inventory, page-local demos, and deployment boundaries.
- Read the [design philosophy](philosophy/) for plane, axis, and selection principles.
- Choose a responsibility from the [component inventory](components/), then verify its contract, defaults, keyboard behavior, and interactive demo on the component page.
- See small arrangements in [Examples](examples/) using the same native renderer.

The root locale is Japanese. These [Japanese docs](../) and this English tree are manually authored with matching paths. The sync script checks path parity and rejects root-absolute internal links.
