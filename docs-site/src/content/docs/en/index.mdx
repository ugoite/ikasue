# Getting Started

ikasue is a framework- and language-neutral UI substrate whose runtime is the Web. Its public ABI is Custom Elements, JSON-safe properties, data-only CustomEvents, command methods, and CSS custom properties. Start with [Host environments](guides/hosts/), then choose Flex, Stack, Grid, DataGrid, or the component that owns the interaction state.
