The same component system can produce very different information shapes. These five construction examples are individually navigable, and each page includes the actual rendered surface, copyable JavaScript and Rust tabs that explain the same page, and the ikasue components used.

## Five site shapes

- [Dense operations dashboard](./operations-dashboard/) — judge filters, a queue, detail, and status in one workspace.
- [Editor + preview](./editor-preview/) — read editing and preview side by side while separating confirmed values from draft state.
- [Planning / calendar](./planning-calendar/) — compare days horizontally and read each day’s events vertically.
- [Field / mobile service](./field-mobile-service/) — keep job context and evidence available on an unreliable network.
- [Observability / incident console](./observability-incident-console/) — investigate timeline, service state, and incident detail together.

The shared construction rules are explained in [Usage](../guides/usage/) and [Behavioral contracts](../guides/behavioral-contracts/). On each page, compare the plane axis, the layout component that owns space, and the information component that owns values and status.
