Examples are not a separate site for complex product shapes. This start-here page keeps the arrangement small so you can see how axis, available space, fit, and focus are resolved when a few elements share one plane.

## Start with these arrangements

- [Vertical](../components/vertical/) — place `one → two → three` from top to bottom. See how `elastic`, focus, and navigation respond when height is tight.
- [Horizontal](../components/horizontal/) — place `one → two → three` from left to right. When width is tight, read the constrained plane with arrows and region selection instead of page-first scrolling.
- [Usage](../guides/usage/) — read the smallest contract for composing a plane in an existing app.

Both component pages use the same registry and public Custom Elements inside the Starlight embedded demo. Change fit, then inspect focus and navigation in the constrained plane.
