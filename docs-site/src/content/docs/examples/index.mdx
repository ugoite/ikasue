Examplesは、複雑な画面を並べるための別サイトではありません。少数の要素を同じplaneへ置くと、axis、利用可能なspace、fit、focusがどう決まるかを最初に確認する場所です。

## まず見る配置

- [Vertical / 縦平面](../components/vertical/) — `one → two → three`を上から下へ置く。高さが足りないときは`elastic`、focus、navigationの関係を見る。
- [Horizontal / 横平面](../components/horizontal/) — `one → two → three`を左から右へ置く。幅が足りないときも、page-first scrollingではなく矢印と領域選択で読む。
- [使い方](../guides/usage/) — compositionを既存のappへ組み込むときの最小契約を読む。

両方のcomponent pageは同じregistryとpublic Custom Elementsを使うStarlight内のembedded demoです。fitを変え、制約されたplaneのfocusとnavigationを確認してください。
