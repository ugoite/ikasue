同じcomponent systemでも、情報のshapeが変わればplaneの使い方は変わります。ここでは、5つのconstruction exampleを個別ページで確認できます。それぞれのページに、実際に描画するsurface、同じ画面を説明するJavaScriptとRustのcode tab、使用するikasue componentsを収録しています。

## 5つのsite shape

- [Dense operations dashboard / 高密度operations dashboard](./operations-dashboard/) — filter、queue、detail、statusを一つのworkspaceで判断する。
- [Editor + preview / editorとpreview](./editor-preview/) — 確定値とdraftを分けながら、編集とpreviewを横に読む。
- [Planning / calendar](./planning-calendar/) — dayを横に比較し、各dayのeventを縦に読む。
- [Field / mobile service](./field-mobile-service/) — 不安定なnetworkでもjob contextとevidenceを保持する。
- [Observability / incident console](./observability-incident-console/) — timeline、service state、incident detailを一つのconsoleで調べる。

同じconstruction ruleは、[使い方](../guides/usage/)と[behavioral contracts](../guides/behavioral-contracts/)で説明しています。各ページでは、planeのaxis、spaceを所有するlayout component、値とstatusを所有するinformation componentの関係を比較してください。
