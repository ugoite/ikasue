ikasueは、情報密度の高いworkspaceのためのframework-neutralなcomponent systemです。すべての領域を一枚のplane上の順序と空間配分として扱い、新しい情報は意味のあるedgeから入り、既存の情報に場所を譲ります。

## まず読む場所

- [概要](overview/)で、package、component inventory、component page内のdemo、公開境界を確認する。
- [平面適応UIの思想](philosophy/)で、plane、axis、selectionの考え方を読む。
- [コンポーネント一覧](components/)から責務を選び、各component pageで契約・既定値・keyboard behavior・interactive demoを確認する。
- [例](examples/)で、同じnative rendererを使った小さな配置を見る。

root localeは日本語です。[English docs](en/)も同じpath treeを持つ手書きのlocaleとして管理しています。同期scriptはpathの一致とroot-absolute internal linkの混入を検査します。
