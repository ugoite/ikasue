# はじめに

ikasueは、Webを実行環境とするframework/language-neutralなUI substrateです。公開ABIはCustom Elements、JSON-safe properties、data-only CustomEvents、command methods、CSS custom propertiesです。まず[ホスト環境から使う](guides/hosts/)で境界を確認し、Flex、Stack、Grid、DataGridなどのcomponentへ進みます。
